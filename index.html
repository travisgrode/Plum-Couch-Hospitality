What I help with

The goal is to spread the feeling of being remembered to more guests, not just the ones a favorite host already knows by name. But you have to earn the right to scale it first. This is the plumbing underneath that — the Host Reach Model, built fractional or project-based depending on what your program needs.

Diagnostic

I go through the list, the coding, the comp spend, and the team itself to find where the program is leaking value. Who's getting a host's time and whether it's the right call, in plain numbers.

Program design

I build the system from the ground up: coding criteria for who deserves a host, player-level goals built from real play history, reinvestment logic that says what a comp is actually supposed to buy, and the visibility to put it all in one place so a host can run their book like a business.

Host training

I train the hosts myself. Not a slide deck handed to a third party. How to run a book like a business, what great hosts already do, and how to make it repeatable across a team.
